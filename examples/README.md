# Assessments

- `provider-peer-comparison-v1.json` is a deterministic Provider Analytics schema 1.2 example with
  three strict compatible providers and no pricing input.
- `provider-peer-comparison-v1.md` is the corresponding human-readable report.
- `provider-value-comparison-v1.json` adds three normalized pricing quotes and compatible relative
  value outcomes.
- `provider-value-comparison-v1.md` is the corresponding pricing-aware Markdown report.
- `assessment-example.json` remains the original foundation placeholder.
