# Discovery Schemas

Versioned JSON contracts for privacy-safe Agent Discovery output.

- `system.schema.json`: operating system and Python runtime.
- `hardware.schema.json`: CPU, memory, and architecture capacity.
- `virtualization.schema.json`: VM or container inference.
- `provider.schema.json`: offline provider inference.
- `network.schema.json`: privacy-safe networking capabilities.
- `result.schema.json`: complete discovery document, schema version `1.0.0`.
