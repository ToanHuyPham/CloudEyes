# Profiles

Versioned benchmark and assessment protocols.

Implemented:

- `general` v1 — portable CPU, memory, and basic sequential storage smoke test.
- `storage` v1 — bounded sequential, random, and fsync measurements with raw evidence.
- `networking` v1 — explicit-endpoint DNS, TCP, TLS, HTTP, throughput, and loss measurements.
- `compute` v1 — bounded single-process and multi-process CPU measurements with raw evidence.

Planned next:

- Shared timeout and sample-quality policy hardening.
