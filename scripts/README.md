# Scripts

## Environment installation

- `install.sh`: installs OS dependencies and CloudEyes on Linux distributions.
- `install.ps1`: installs Python and CloudEyes on Windows 10/11.

Both installers create `.venv` and avoid replacing the operating system's
Python interpreter. See `docs/installation.md`.

## Development helpers

The remaining scripts handle tests, linting, schema validation, migrations,
example generation, catalog generation, and releases.
